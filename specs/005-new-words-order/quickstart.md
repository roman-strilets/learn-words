# Quickstart: проверка порядка новых слов и отметки «Учить первым»

## Предварительно

```bash
yarn setup
uv run --directory backend alembic upgrade head   # добавит words.priority
yarn dev
```

## Автоматические проверки

```bash
yarn test:api
yarn typecheck
yarn build
uv run --directory backend ruff check app tests
```

Тесты, которые должны появиться в `backend/tests/test_api.py` (таблично, где
возможно):

| Что проверяем | Требование |
|---|---|
| `GET /settings` без сохранённого значения → `oldest_first` | FR-002 |
| `PUT /settings` сохраняет, следующий `GET` его отдаёт; неизвестное значение → 422 | FR-001, FR-003 |
| `mode=learn` при `oldest_first` отдаёт первые 5 слов по `id`, при `newest_first` — последние 5 от нового к старому | FR-004, SC-001, SC-004 |
| Замена после «Уже знаю» берётся по выбранному порядку | FR-004 |
| 3 поднятых из 20 → первые три слова занятия — поднятые, затем 2 по порядку; при 7 поднятых занятие из 5 поднятых | FR-009, SC-002 |
| Поднятые не обходят дневной лимит | FR-012 |
| `PUT /words/{id}/priority` ставит и снимает; у слова в изучении `true` → 409, `false` → 200 | FR-007, FR-008 |
| «Изучить», «Уже знаю» и смена статуса снимают отметку; возврат в «Новое» — без отметки | FR-010 |
| `GET /words?priority=true` вместе с `search` | FR-011 |
| Ни отметка, ни смена порядка не пишут в `review_log` | FR-014 |
| `mode=review` не зависит от настройки и отметок | FR-013 |

В `backend/tests/test_import.py`: повторный импорт не сбрасывает `priority` у
существующей строки (FR-015).

## Ручные сценарии

1. **Умолчание.** На чистой базе с импортом открыть «Настройки»: выбрано
   «В порядке добавления». «Учить слова» даёт первые 5 строк `dictionary.csv`.
2. **Сначала новые.** Выбрать «Сначала недавно добавленные», добавить слово через
   «Добавить слово», начать «Учить слова»: это слово — первое на знакомстве.
   Перезагрузить страницу «Настройки» — выбор на месте.
3. **Замена.** На знакомстве нажать «Уже знаю»: пришедшая замена — следующее по
   выбранному порядку слово.
4. **Поднятие.** В «Словаре» отметить «Учить первым» три слова из середины
   списка; фильтр «Учить первыми» показывает ровно их. Начать «Учить слова»:
   эти три слова — первые. После «Изучить» у них в «Словаре» нет отметки и
   кнопки поднятия.
5. **Только новые.** У слова в статусе «Изучается» кнопки «Учить первым» нет.
   Перевести его в «Новое» (с подтверждением): кнопка появилась, отметки нет.
6. **Повторение не затронуто.** «Повторить слова» даёт те же слова, что до смены
   настройки.
