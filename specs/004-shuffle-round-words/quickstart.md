# Quickstart: проверка случайного порядка слов в раундах

## Подготовка

```bash
yarn setup          # один раз
yarn dev            # бэкенд + фронтенд
```

Для ручных сценариев нужны не меньше 5 новых слов (для «Изучения») и не меньше 5 слов
с подошедшим сроком (для «Повторения»).

## Автоматические проверки

```bash
yarn test:api
yarn typecheck
yarn build
uv run --directory backend ruff check app tests
```

Что должны покрывать новые тесты:

| Проверка | Где |
|---|---|
| `order_round` при `n = 0, 1, 2, 3, 5` на множестве семян: состав сохранён, порядок ≠ `previous` (n ≥ 2), первый ≠ `last` (n ≥ 3) | `backend/tests/test_exercises.py` |
| Первый элемент равен `last` и совпадение с `previous` — оба случая срабатывают на подобранном семени и чинятся | `backend/tests/test_exercises.py` |
| План `review` и `POST /study/rounds` из 5 слов: соседние раунды различаются, стык без повтора слова | `backend/tests/test_api.py` |
| `POST /study/rounds` из 2 слов: раунды чередуют два порядка | `backend/tests/test_api.py` |
| На 1 000 перестановках первого раунда из 5 элементов доля каждого элемента на первой позиции — 15–25 % (SC-003) | `backend/tests/test_exercises.py` |

## Ручные сценарии

1. **Разный порядок (US1).** Открыть «Повторить слова», отвечать верно и выписать
   слова каждого раунда. Порядок ни одного раунда не должен повторять порядок
   предыдущего.
2. **Не порядок словаря (US1, сц. 3).** Дважды перезагрузить страницу занятия
   и сравнить первый раунд: порядок хотя бы раз меняется.
3. **Изучение (US1, сц. 4).** Пройти знакомство в «Учить слова». Порядок первого
   раунда не обязан совпадать с порядком знакомства. За несколько занятий он хотя бы
   раз отличается.
4. **Стык после ошибки (US2, сц. 2).** В раунде из 5 слов ошибиться на одном слове
   и исправить его последним. Следующий раунд начинается с другого слова.
5. **Два слова (US2, сц. 3).** Оставить в занятии 2 слова (например, отметив остальные
   «Уже знаю» при исчерпанных новых словах). Раунды чередуют два порядка. Такое занятие
   в интерфейсе собрать трудно, а сценарий закрыт автотестом `test_learn_rounds_differ_in_order`,
   поэтому вручную его можно пропустить.
6. **Выбывшее слово.** Посреди занятия в другой вкладке пометить слово «Знаю».
   Оставшиеся раунды идут без него, и соседние раунды по-прежнему различаются
   по порядку.
7. **Длина занятия (SC-005).** Безошибочное занятие из 5 слов — 20 карточек
   упражнений («Осталось карточек» в начале первого раунда показывает 20).
