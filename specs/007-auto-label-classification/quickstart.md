# Quickstart: проверка автоматической разметки

## Предварительно

```bash
yarn setup
uv run --directory backend alembic upgrade head   # добавит labels.description
yarn dev
```

Для ручных сценариев нужна модель: локальная Ollama на `http://localhost:11434` с
моделью `nimble` (`curl -s localhost:11434/api/tags` перечисляет `nimble:latest`).
Автоматическим проверкам модель не нужна.

## Автоматические проверки

```bash
yarn test:api
yarn typecheck
yarn build
uv run --directory backend ruff check app tests
```

Тесты в `backend/tests/test_api.py` и новом `backend/tests/test_classifier.py`. В
тестах API классификатор подменён фейком через `get_classifier`, в тестах адаптера
HTTP подменён `httpx2.MockTransport` (R11). Контракт — [contracts/api.md](./contracts/api.md),
правила — [data-model.md](./data-model.md).

## Ручные сценарии

1. **Контрольный набор (SC-002).** Завести метки «кухня», «тело», «растение» и 16
   слов примера пользователя (`spoon` … `cloud`). «Словарь» → «Разметить
   автоматически» → «Запустить». Не меньше 14 слов размечены верно; `bicycle`,
   `democracy`, `guitar`, `cloud` без меток. Повторный запуск не меняет набор меток
   (SC-003).
2. **Этапы (US2).** Фильтр «Без меток», «Не больше 40», пачка 10. Прогресс
   обновляется после каждой пачки. «Остановить» после второй — панель ждёт конца
   пачки, показывает «Продолжить с «…»». Перезагрузить страницу, открыть разметку:
   «С места остановки» предложено, размер пачки 10. Продолжить — обрабатываются
   оставшиеся.
3. **Сбой (FR-018).** Во время разметки остановить Ollama. Панель показывает
   «Сервис разметки недоступен…», прежние пачки на словах, кнопка «Продолжить».
4. **Настройки (US3).** «Настройки» → «Разметка»: значения по умолчанию. Модель
   `nimbel` → «Проверить подключение» → «Модель «nimbel» не найдена». «Сбросить» →
   снова `nimble`, проверка проходит. Перезагрузить — значения на месте.
5. **Описание метки.** Метка «B2» без описания и с описанием «advanced vocabulary
   (CEFR B2)»: на одних и тех же словах разметка ведёт себя иначе.
6. **Без меток (FR-010).** Удалить все метки — кнопка «Запустить» недоступна, панель
   предлагает завести метки.
