# Feature Specification: Занятие по группе слов

**Feature Branch**: `010-label-group-study`

**Created**: 2026-10-16

**Status**: Draft

**Input**: User description: "давай добавим функционал изучения группы слов. например имеющей определенные метку. я предлагаю из всего цикла обучения, в данном случае, убрать первый этап, когда слово показывается с переводом. т.е. сделать похожим на "повторение". причём обучение группы слов не должно пересекаться с основным обучением. т.е. если учу слово, которое находится в какой-то группе. т.е. если я начинаю учить группу, то прогресс для этого слова не должен влиять на основной прогресс. так же надо, чтобы не было ограничений по количеству слов в день, когда учишь по группе. также если прошел до конца группу, то начинаешь с начала. предлагаю в данном случае не делать интервальное обучение. просто учить по кругу, но при этом чтобы порядок слов отличался"

## Clarifications

### Session 2026-10-16

- Q: Входят ли в группу слова со статусами «Знаю» и «Отложено»? → A: Да, в группу входят все слова с меткой в любом статусе.
- Q: Нужно ли такое же занятие для меток фраз? → A: Нет, в этой версии только метки слов; занятие по метке фраз записывается в README, в «Что не сделано».
- Q: Откуда брать неверные варианты ответа в карточках выбора занятия по группе? → A: Из всего словаря слов, как в обычных занятиях; метки на подбор вариантов не влияют.
- Q: Как занятия по группе отражаются на странице «Статистика»? → A: Никак: ответы пишутся в журнал с пометкой, но статистика их не считает и отдельного блока не показывает.
- Q: Что делать, когда в круге осталось меньше слов, чем размер порции? → A: Взять остаток круга и добрать порцию из начала нового круга, без повтора слов внутри занятия.

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Позаниматься словами одной метки (Priority: P1)

Пользователь хочет подтянуть тему «кухня» — без оглядки на то, у каких её слов
подошёл срок. С главной он запускает «Учить группу» и выбирает метку «кухня».
Занятие берёт порцию слов с этой меткой (по умолчанию 5) и сразу, без карточек
знакомства, ведёт те же пять раундов упражнений, что и «Повторить слова»: по
раунду на тип, все слова порции в каждом раунде, ошибка возвращает слово в конец
раунда с заново собранной карточкой. В конце пользователь видит итог занятия и
может сразу взять следующую порцию той же группы.

**Why this priority**: Это суть просьбы — тренировать тему целиком. Без самого
занятия остальные истории не имеют смысла.

**Independent Test**: Дать метку «кухня» 3 словам из 20. Запустить «Учить
группу» → «кухня»: первая карточка — уже упражнение (не знакомство), во всех
раундах только эти 3 слова, раундов пять в обычном порядке.

**Acceptance Scenarios**:

1. **Given** у метки «кухня» 12 слов, **When** пользователь запускает «Учить
   группу» с этой меткой, **Then** занятие берёт 5 слов только с этой меткой и
   начинается с первого раунда упражнений, без карточек знакомства.
2. **Given** идёт занятие по группе, **When** пользователь проходит раунды,
   **Then** порядок раундов, перемешивание слов между раундами и повтор после
   ошибки работают так же, как в «Повторить слова».
3. **Given** у метки 3 слова — меньше размера порции, **When** запущено занятие,
   **Then** в нём все 3 слова.
4. **Given** занятие по группе пройдено, **When** оно завершается, **Then**
   пользователь видит итог и может одним действием начать следующую порцию той
   же группы.
5. **Given** у метки нет ни одного подходящего слова, **When** пользователь
   выбирает группу, **Then** занятие не запускается, а пользователь видит, что в
   группе нечего учить.
6. **Given** пользователь выбирает группу, **When** открыт выбор, **Then** у каждой
   метки видно число её слов и сколько из них уже пройдено в текущем круге.

### User Story 2 — Группа не трогает основное обучение (Priority: P1)

Пользователь учит группу «кухня», в которой есть слова в любом состоянии:
новые, в изучении, на повторении. Занятие по группе — тренировка «сбоку»:
оно не меняет ни статус слова, ни его расписание, ни лёгкость, ни счётчик
забываний, не тратит дневной лимит новых слов и не снимает отметку «Учить
первым». «Учить слова» и «Повторить слова» после занятия по группе подбирают
те же слова, что и до него.

**Why this priority**: Прямое требование: прогресс в группе «не должен влиять на
основной прогресс». Без изоляции занятие по группе ломало бы расписание.

**Independent Test**: Записать статусы, сроки и счётчики всех слов группы и
список слов, которые предложат «Учить слова» и «Повторить слова». Пройти по
группе занятие с ошибками. Сравнить: всё совпадает до последнего поля.

**Acceptance Scenarios**:

1. **Given** в группе есть новое слово, **When** оно прошло занятие по группе,
   **Then** оно осталось «Новым» и по-прежнему придёт на знакомство в «Учить
   слова».
2. **Given** в группе есть слово на повторении со сроком через 10 дней,
   **When** в занятии по группе оно отвечено с ошибкой, **Then** его статус,
   срок, лёгкость и счётчик забываний не изменились.
3. **Given** в группе есть слово с подошедшим сроком, **When** оно прошло
   занятие по группе без ошибок, **Then** оно по-прежнему придёт в «Повторить
   слова» — занятие по группе не засчитывается как повторение.
4. **Given** сегодня дневной лимит новых слов уже исчерпан, **When** пользователь
   запускает занятие по группе, **Then** оно запускается, а лимит не меняется.
5. **Given** пользователь прошёл 10 порций группы за день, **When** он запускает
   одиннадцатую, **Then** ограничений нет — занятие запускается.
6. **Given** у нового слова в группе отметка «Учить первым», **When** слово прошло
   занятие по группе, **Then** отметка осталась.
7. **Given** в статистике за сегодня видно число ответов по словам, **When**
   пользователь проходит занятие по группе, **Then** основные числа статистики не
   меняются.

### User Story 3 — Группа проходится по кругу в новом порядке (Priority: P1)

Порции идут подряд по всей группе: каждое следующее занятие берёт слова, ещё не
пройденные в текущем круге, пока не будут пройдены все. После этого начинается
новый круг — снова по всем словам группы, но в другом порядке, чем в прошлом
круге. Интервальных повторений нет: слово, отвеченное с ошибкой, не приходит
раньше других, а просто ждёт своего места в следующем круге.

**Why this priority**: Без кругового прохода пользователь раз за разом видел бы
одни и те же первые слова группы, а другие не попадались бы.

**Independent Test**: Дать метку 7 словам, размер порции 5. Первое занятие —
5 слов, второе — оставшиеся 2 из первого круга плюс 3 первых слова нового круга
(не из этих двух). Порядок слов во втором круге отличается от первого.

**Acceptance Scenarios**:

1. **Given** у группы 12 слов и порция 5, **When** пользователь проходит три
   занятия подряд, **Then** первые два дают по 5 слов текущего круга, а третье —
   2 оставшихся слова круга и 3 слова из начала нового круга; ни одно слово не
   повторяется ни внутри круга, ни внутри одного занятия.
2. **Given** все слова группы пройдены в текущем круге, **When** пользователь
   запускает следующее занятие, **Then** начинается новый круг по всем словам
   группы.
3. **Given** начинается новый круг группы из трёх и более слов, **When** слова
   выстраиваются, **Then** их порядок отличается от порядка прошлого круга, а
   первое слово нового круга не совпадает с последним словом прошлого.
4. **Given** занятие по группе прервано посреди раундов, **When** пользователь
   запускает группу снова, **Then** слова, не прошедшие все раунды, остаются
   непройденными в текущем круге и приходят снова.
5. **Given** пользователь прошёл часть круга, **When** он перезагружает страницу
   или открывает приложение в другом браузере, **Then** место в круге
   сохранилось.
6. **Given** пользователь в середине круга группы «кухня» занимается группой
   «тело», **When** он возвращается к «кухне», **Then** круг «кухни» продолжается
   с того же места: у каждой группы свой круг.

### User Story 4 — Начать круг группы заново (Priority: P3)

Пользователь прошёл полкруга, но хочет начать тему с начала — например,
после того как добавил в неё много слов. Он нажимает «Начать круг заново»:
место в круге сбрасывается, и следующее занятие начинает новый круг в новом
порядке.

**Why this priority**: Удобство. Круг и так замыкается сам, а новые слова
попадают в текущий круг без сброса.

**Independent Test**: Пройти 1 занятие из группы на 12 слов, нажать «Начать круг
заново»: у группы снова «пройдено 0 из 12», следующее занятие начинает новый
круг.

**Acceptance Scenarios**:

1. **Given** в текущем круге группы пройдено 5 из 12 слов, **When** пользователь
   начинает круг заново, **Then** пройдено 0 из 12, а основной прогресс слов не
   изменился.

---

### Edge Cases

- **Метку дали слову посреди круга**: слово становится частью текущего круга как
  непройденное и придёт до конца круга.
- **Метку сняли со слова или слово удалили посреди круга**: слово выпадает из
  группы и из её круга; занятие, в котором оно уже идёт, продолжается без него,
  как при удалении слова в обычном занятии.
- **Метку удалили**: группы больше нет, её круг забыт; если занятие по ней шло,
  его нельзя продолжить с новой порцией.
- **Метку переименовали**: это та же группа, круг продолжается.
- **В группе одно слово**: занятие из одного слова, пять раундов по одной
  карточке; каждый круг — то же слово.
- **В группе два слова**: новый круг лишь чередует два порядка, как раунды в
  обычном занятии.
- **В круге осталось меньше слов, чем порция**: занятие берёт оставшиеся слова
  круга и добирает до полной порции из начала нового круга, пропуская слова,
  которые уже есть в этом занятии. Остаток старого круга в новом круге
  по-прежнему ждёт своей очереди и придёт ещё раз позже.
- **Занятие на стыке кругов прервано**: остаток старого круга остаётся
  непройденным, добранные слова нового круга — тоже; порядок нового круга уже
  выбран и при повторном запуске не перетасовывается.
- **Группа меньше порции** (например, 3 слова при порции 5): добор не делается —
  в занятии все слова группы по одному разу, без повторов внутри занятия.
- **Слово группы в статусе «Знаю» или «Отложено»**: входит в группу наравне с
  остальными и после занятия остаётся в своём статусе.
- **Слову сменили статус посреди круга** (вручную или обычным занятием): место
  слова в круге не меняется — круг не зависит от статуса.
- **Варианты ответа**: подбираются так же, как в обычных занятиях, из всего
  словаря слов, а не только из группы; метки на подбор вариантов не влияют.
- **Пользователь бросил занятие по группе и запустил «Повторить слова»**:
  обычное занятие идёт как всегда; брошенное занятие по группе круг не сдвигает.

## Requirements *(mandatory)*

### Functional Requirements

**Запуск**

- **FR-001**: Главная ДОЛЖНА предлагать занятие «Учить группу» с выбором одной
  метки; у каждой метки в выборе видно число её слов и сколько пройдено в текущем
  круге. Метки без подходящих слов не запускают занятие.
- **FR-002**: Занятие по группе ДОЛЖНО брать порцию (по умолчанию 5 слов) только
  из слов с выбранной меткой.
- **FR-003**: Занятие по группе ДОЛЖНО начинаться сразу с раундов упражнений, без
  карточек знакомства и без «Уже знаю».
- **FR-004**: Раунды занятия по группе ДОЛЖНЫ идти по тем же правилам, что в
  «Повторить слова»: те же пять типов упражнений в том же порядке, все слова
  порции в каждом раунде, перемешивание между раундами, возврат слова в конец
  раунда после ошибки с заново собранной карточкой.
- **FR-004a**: Неверные варианты ответа в карточках выбора ДОЛЖНЫ подбираться из
  всего словаря слов по тем же правилам, что в обычных занятиях; принадлежность к
  группе на подбор не влияет.
- **FR-005**: По завершении занятия пользователь ДОЛЖЕН видеть итог и иметь
  возможность одним действием начать следующую порцию той же группы.

**Изоляция от основного обучения**

- **FR-006**: Занятие по группе НЕ ДОЛЖНО менять статус, шаг изучения, интервал,
  срок, лёгкость и число забываний ни одного слова, а также отметку «Учить
  первым».
- **FR-007**: Занятие по группе НЕ ДОЛЖНО расходовать дневной лимит новых слов и
  НЕ ДОЛЖНО само ограничиваться числом слов или занятий в день.
- **FR-008**: «Учить слова» и «Повторить слова» ДОЛЖНЫ подбирать слова так же,
  как если бы занятий по группе не было.
- **FR-009**: Правильность ответа в занятии по группе ДОЛЖНА определяться только
  сервером, как в обычных занятиях.
- **FR-010**: Каждый ответ в занятии по группе ДОЛЖЕН записываться в журнал
  ответов с пометкой, что это занятие по группе; страница «Статистика» (ответы по
  дням, распределение по статусам) и итоги обычных занятий НЕ ДОЛЖНЫ учитывать
  эти ответы, и отдельного блока по группам на ней нет.

**Круг**

- **FR-011**: Каждая порция ДОЛЖНА брать слова группы, ещё не пройденные в
  текущем круге, в порядке этого круга; слово считается пройденным, когда оно
  прошло все раунды занятия.
- **FR-012**: Когда все слова группы пройдены, следующее занятие ДОЛЖНО начинать
  новый круг по всем текущим словам группы.
- **FR-012a**: Если в текущем круге осталось меньше непройденных слов, чем размер
  порции, занятие ДОЛЖНО взять их все и добрать порцию из начала нового круга,
  пропуская слова, уже взятые в это занятие; одно слово НЕ ДОЛЖНО встречаться в
  занятии дважды. Порядок нового круга выбирается один раз и не меняется при
  повторном запуске прерванного занятия.
- **FR-013**: Порядок слов в новом круге ДОЛЖЕН быть случайным и отличаться от
  порядка прошлого круга; при трёх и более словах первое слово нового круга НЕ
  ДОЛЖНО совпадать с последним словом прошлого.
- **FR-014**: Ошибки в занятии по группе НЕ ДОЛЖНЫ менять место слова в круге и
  не делают его чаще: интервального расписания в группе нет.
- **FR-015**: Место в круге ДОЛЖНО храниться отдельно для каждой метки, переживать
  перезагрузку страницы и быть одинаковым в любом браузере.
- **FR-016**: Прерванное занятие НЕ ДОЛЖНО отмечать пройденными слова, не
  прошедшие все раунды.
- **FR-017**: Слово, получившее метку посреди круга, ДОЛЖНО войти в текущий круг
  непройденным; слово, потерявшее метку или удалённое, ДОЛЖНО выпасть из круга.
  Удаление метки ДОЛЖНО удалять и её круг.
- **FR-018**: Пользователь ДОЛЖЕН иметь возможность начать круг группы заново;
  сброс НЕ ДОЛЖЕН трогать основной прогресс слов.

**Состав группы**

- **FR-019**: В группу ДОЛЖНЫ входить все слова с выбранной меткой в любом
  статусе: «Новое», «Изучается», «На повторении», «Знаю», «Отложено».
- **FR-020**: Занятие по группе ДОЛЖНО работать только для меток слов; метки
  фраз в выборе группы не предлагаются, фразы в занятие по группе не попадают.

### Key Entities

- **Группа**: множество слов, у которых стоит выбранная метка, в любом статусе.
  Существует, пока существует метка; состав меняется вместе с метками слов.
- **Круг группы**: текущий проход по группе — случайный порядок её слов и отметки,
  какие из них уже пройдены. Один на метку; при окончании заменяется новым кругом
  в новом порядке. Не связан с прогрессом слов.
- **Ответ в занятии по группе**: запись журнала ответов — какое слово, какое
  упражнение, верно ли, с какой попытки, в каком занятии — с пометкой, что это
  занятие по группе. Не влияет на расписание и основную статистику.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: От главной до первой карточки занятия по группе — не больше 2
  действий (выбрать метку, запустить).
- **SC-002**: После любого числа занятий по группе статусы, сроки, лёгкость,
  число забываний и отметки «Учить первым» всех слов совпадают с тем, что было
  до них (проверяется сравнением до и после), а «Учить слова» и «Повторить
  слова» предлагают те же слова.
- **SC-003**: За один полный круг группы из N слов каждое слово приходит ровно
  один раз; за K полных кругов — ровно K раз.
- **SC-004**: Два подряд идущих круга группы из трёх и более слов никогда не
  имеют одинаковый порядок.
- **SC-005**: Можно пройти 20 порций одной группы подряд за день без какого-либо
  отказа по лимиту.
- **SC-006**: Место в круге одинаково после перезагрузки и в другом браузере в
  100% случаев.

## Assumptions

- Группа — это слова одной метки; группы из нескольких меток, из «Без меток» или
  из произвольно выбранных слов в эту версию не входят.
- Размер порции по умолчанию — 5 слов, как у «Повторить слова», и настраивается
  отдельно от размеров обычных занятий.
- Новые слова попадают в занятие по группе без знакомства: пользователь сам
  предложил убрать этот этап; первый раунд с выбором из вариантов служит
  знакомством.
- Отдельная статистика по группам — не в этой версии; журнал с пометкой позволит
  добавить её позже без новых данных.
- Слово, пройденное в группе, считается пройденным независимо от ошибок: круг
  отражает, что слово было показано, а не насколько хорошо его знают.
- Одно занятие идёт за раз: занятие по группе и обычное занятие не идут
  одновременно в одной вкладке, но обычное занятие можно начать, бросив
  занятие по группе.
- Приложение однопользовательское: круги групп общие для всего приложения.
- Занятие по метке фраз в эту версию не входит и записывается в README, в «Что не
  сделано». Пункт «Занятие по метке» оттуда снимается или уточняется: слова одной
  темы теперь можно тренировать по кругу, но обычное расписание по метке не
  фильтруется.
