# Quickstart: проверка занятия по группе

## Автоматические проверки

```bash
yarn test:api                                   # pytest, временная SQLite
uv run --directory backend ruff check app tests
yarn typecheck
yarn build
```

Что должно быть покрыто тестами (`backend/tests/`):

| Файл | Что проверяет |
|---|---|
| `test_group_cycles.py` | Чистая функция круга, табличные случаи: первый круг; порции 5/5/2+3 при 12 словах; группа меньше порции; стык с остатком без повтора слов; новый круг ≠ прошлому и не начинается с последнего (≥ 3 слов); 1 и 2 слова; дописывание новых членов; слова, потерявшие метку |
| `test_group_study_api.py` | Маршруты из [contracts/api.md](contracts/api.md): выбор групп, сборка, ответы по новому слову, 404/409, `finish` и его идемпотентность, рестарт, удаление метки и слова; **изоляция** — снимок `progress`, `words.priority`, `review_log`, ответов `/api/stats/*` и составов `/api/study/session` до и после занятий по группе совпадает |
| `test_migrations.py` | `alembic upgrade head` поверх базы со словами создаёт `group_cycle_words` и `group_review_log`, существующие таблицы не меняются; `downgrade` удаляет только их |

## Ручная проверка

Предусловие: `yarn dev`, в словаре есть слова; на вкладке «Настройки → Метки»
заведена метка «кухня», и её получили 7 слов: два новых, по одному в изучении, на
повторении, «Знаю» и «Отложено», ещё одно любое.

1. **Запуск за два действия** — на главной в блоке «Слова» нажать «Учить группу»:
   видна «кухня · 7 слов · пройдено 0 из 7». «Учить» → первая карточка —
   выбор рус → англ, знакомства нет (US1).
2. **Пять раундов** — пройти занятие с одной ошибкой: раунды идут как в «Повторить
   слова», ошибка возвращает слово в конец раунда (FR-004). Итог показывает
   «Следующая порция» (FR-005).
3. **Изоляция** — до шага 1 запомнить на главной числа «Учить слова» / «Повторить
   слова» и «Ответов сегодня», а в «Словаре» статусы и сроки этих 7 слов. После
   занятия всё совпадает; новые слова по-прежнему «Новые» (US2, SC-002).
4. **Стык кругов** — «Следующая порция»: в занятии 2 оставшихся слова и 3 слова
   нового круга, ни одно не повторяется. В выборе групп — «пройдено 3 из 7» в новом
   круге (US3, FR-012a).
5. **Новый порядок** — пройти круг до конца ещё раз: порядок слов во втором круге
   отличается от первого (SC-004).
6. **Прерывание** — начать порцию, ответить на пару карточек и уйти на главную.
   Снова «Учить»: те же слова, место в круге не сдвинулось (FR-016).
7. **Другой браузер** — открыть выбор групп в другом браузере: то же «пройдено X из
   7» (FR-015).
8. **Без лимитов** — исчерпать дневной лимит новых слов в «Учить слова»; «Учить
   группу» всё равно запускается, порций сколько угодно (FR-007).
9. **Метки посреди круга** — дать метку восьмому слову: «7 → 8 слов», оно придёт
   до конца текущего круга. Снять метку с другого слова — оно пропадает из круга
   (FR-017).
10. **Начать круг заново** — «пройдено 0 из 8», прогресс слов не изменился (US4).
11. **Удаление метки** — удалить «кухня»: группы нет в выборе; слова и их прогресс
    на месте.
