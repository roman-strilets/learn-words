# Data Model: Занятие по группе слов

Существующие таблицы (`words`, `progress`, `review_log`, `labels`, `word_labels`,
таблицы фраз) не меняются. Одна миграция создаёт две новые таблицы.

## Группа (вычисляется, не хранится)

Члены группы метки `L` — слова со связкой `word_labels(word_id, L)`, в любом статусе
(FR-019). Отдельной таблицы нет: состав всегда читается из связок, поэтому любая
правка меток — формой, авторазметкой или удалением метки — сразу меняет группу.

## `group_cycle_words` — круг группы

Строка — место одного слова в одном круге одной метки.

| Колонка | Тип | Ограничения | Смысл |
|---|---|---|---|
| `label_id` | int | PK, FK `labels.id` ON DELETE CASCADE | Метка группы |
| `cycle` | int | PK, ≥ 1 | Номер круга у этой метки |
| `word_id` | int | PK, FK `words.id` ON DELETE CASCADE | Слово |
| `position` | int | NOT NULL | Место слова в порядке круга, с 0; дописанные позже — в конец |
| `done_at` | datetime (naive UTC) | NULL | Когда слово прошло все раунды в этом круге; NULL — ещё не пройдено |
| `done_session_id` | str(36) | NULL | Ключ занятия, в котором слово пройдено, — для идемпотентного `finish` |

Индексы: PK `(label_id, cycle, word_id)`; `ix_group_cycle_words_word_id` по
`word_id` — каскад удаления слова и поиск строк слова в `finish`.

### Правила

- **Текущий круг** метки — наименьший `cycle`, в котором есть непройденная строка
  слова-члена группы. Если таких нет — круг с наибольшим номером, пройденный
  целиком (следующая сборка начнёт новый). Если строк нет вовсе — круга ещё нет.
- **Пройдено в круге** (для выбора группы) — число членов группы с `done_at` в
  текущем круге; члены без строки в текущем круге считаются непройденными.
- Живут не больше двух кругов: текущий и следующий (на стыке). Строки кругов
  меньше текущего удаляются при сборке занятия.
- Строки слов, потерявших метку, не удаляются: они отсекаются соединением с
  `word_labels` и восстанавливают место, если метку вернут.

### Переходы при сборке порции (размер `n`, члены группы `M`)

1. `M` пусто → занятия нет, ничего не пишется.
2. Круга нет → создать круг 1: `order_round(M, previous=None)`.
3. Текущий круг `C` пройден целиком → создать `C+1`, если его ещё нет:
   `order_round(M, previous=порядок C по членам M, last=последний из них)`; `C := C+1`.
4. Члены `M` без строки в `C` (и в `C+1`, если он есть) дописываются в конец круга
   в случайном порядке.
5. Порция = непройденные члены `C` по `position`, первые `n`.
6. Если порция короче `n` и в `M` есть слова вне порции → создать `C+1` по правилу
   шага 3, если его нет, и добрать порцию первыми непройденными членами `C+1`,
   пропуская слова порции.
7. Удалить строки кругов `< C`.

Шаги 2–6 — чистая функция (`app/group_cycles.py`) над списками членов и строк:
вход — `M`, строки метки, `n`, `rng`; выход — слова порции, строки к вставке, номера
кругов к удалению. Сервис только применяет результат.

### Переход при `finish`

Для каждого слова занятия, верно ответившего во всех `EXERCISE_ROUNDS`:
- если у слова уже есть строка с `done_session_id` = ключ занятия — пропустить
  (повторный `finish`);
- иначе в самой ранней непройденной строке слова этой метки поставить
  `done_at = now`, `done_session_id = ключ`.

Слово, не дошедшее до конца раундов, не меняется (FR-016). Ошибки на прохождение
не влияют (FR-014).

### «Начать круг заново»

Создать круг `max+1` по правилу шага 3 относительно последнего круга, удалить все
строки меньших кругов. Прогресс слов не трогается (FR-018).

## `group_review_log` — журнал занятий по группе

По строке на каждый ответ в занятии по группе (FR-010). Не читается статистикой и
`finish` обычных занятий.

| Колонка | Тип | Ограничения | Смысл |
|---|---|---|---|
| `id` | int | PK | |
| `word_id` | int | FK `words.id` ON DELETE CASCADE, NOT NULL, индекс | Слово |
| `label_id` | int | FK `labels.id` ON DELETE SET NULL, NULL | Метка занятия; NULL — метку потом удалили |
| `exercise` | str(24) | NOT NULL | Тип упражнения |
| `correct` | bool | NOT NULL | Засчитан ли ответ сервером |
| `answer` | text | NULL | Что ввёл пользователь |
| `used_hint` | bool | NOT NULL, default false | Подсказка (кроме упражнений без подсказки) |
| `attempt` | int | NOT NULL, default 1 | Номер показа в раунде |
| `quality` | int | NOT NULL | Оценка 0–5 по `derive_quality` — для будущей статистики групп, на расписание не влияет |
| `duration_ms` | int | NULL | Время на карточку |
| `session_id` | str(36) | NOT NULL, индекс | Ключ занятия по группе |
| `created_at` | datetime (naive UTC) | NOT NULL, индекс | Время ответа |

Колонок расписания (`status_*`, `ease_after`, `interval_after`) нет: переходов
расписания в занятии по группе не бывает.

## Конфигурация

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `GROUP_WORDS_PER_SESSION` | 5 | Размер порции занятия по группе |

## Что не меняется

`progress`, `review_log`, `words.priority`, дневной лимит новых слов (`_started_today`
считает только `progress`) — занятие по группе их не читает и не пишет (FR-006–FR-008).
