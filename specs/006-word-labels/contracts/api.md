# API Contract: Метки слов

Все маршруты под `/api`. Ошибки — `{"detail": "<текст по-русски>"}`: конфликт — 409,
неверное значение — 422, отсутствие — 404.

## Типы

```text
LabelRef   { id: int, name: str }                     # метка в составе слова
LabelOut   { id: int, name: str, word_count: int }    # метка в общем списке
LabelInput { name: str }                              # 1…50 символов после обрезки
```

## Метки

### `GET /labels` → 200 `LabelOut[]`

Все метки по названию без учёта регистра, «ё» = «е». `word_count` — число слов с
меткой, 0 у метки без слов.

Маршрут приходит с основой (Phase 2): его читают подсказки формы слова и фильтр.

### `POST /labels` ← `LabelInput` → 201 `LabelOut`

Создаёт метку с `word_count = 0`.
- 409 — метка с тем же названием без учёта регистра уже есть.
- 422 — пустое или длиннее 50 символов.

### `PATCH /labels/{id}` ← `LabelInput` → 200 `LabelOut`

Переименовывает; набор слов не меняется.
- 409 — название занято другой меткой. Смена только регистра своей же метки — 200.
- 404 — метки нет. 422 — как в `POST`.

### `DELETE /labels/{id}` → 204

Удаляет метку и снимает её со всех слов. Слова, прогресс и журнал не меняются.
- 404 — метки нет.

## Слова (изменения)

### `WordOut` / `WordWithProgress`

Новое поле:

```text
labels: LabelRef[]     # по названию без учёта регистра, «ё» = «е»; [] у слова без меток
```

Поле есть везде, где отдаётся слово: `GET /words`, `GET/POST/PATCH /words…`,
`PUT /words/{id}/status`, `PUT /words/{id}/priority`, а также `new_words` и
`replacement` в занятии.

### `POST /words` ← `WordCreate`

Новое необязательное поле:

```text
labels: str[] = []     # названия; существующие берутся по ключу, новые создаются
```

- Слово и новые метки сохраняются одной транзакцией; 409 (значение уже заведено)
  не создаёт ни слова, ни меток.
- 422 — пустое название или длиннее 50 символов.

### `PATCH /words/{id}` ← `WordUpdate`

Новое необязательное поле:

```text
labels?: str[]         # нет поля — метки не меняются; [] — снять все
```

Набор меток заменяется целиком вместе с остальной правкой. 409 откатывает и
правку, и метки.

### `GET /words`

Новый параметр:

```text
label?: int | "none"   # id метки или "none" — слова без меток
```

- Сочетается с `search`, `status`, `priority` по «И».
- Неизвестный `id` — пустая страница (`total: 0`), не 404.
- Иное значение (`label=abc`) — 422.

### Без изменений

`PUT /words/{id}/status`, `PUT /words/{id}/priority`, `DELETE /words/{id}` (связки
удаляются каскадом), все маршруты `/study`, `/stats`, `/settings`.

## Фронтенд (`frontend/src/api`)

- `types.ts`: `LabelRef`, `Label` (= `LabelOut`), `Word.labels`,
  `WordInput.labels?: string[]`.
- `client.ts`: `listLabels`, `createLabel`, `renameLabel`, `deleteLabel`;
  `listWords({ label?: number | 'none' })`.
