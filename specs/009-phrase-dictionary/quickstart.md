# Quickstart: проверка словаря фраз

## Подготовка

```bash
nvm use
yarn db:upgrade        # миграция создаёт таблицы фраз; таблицы слов не меняются
yarn dev               # фронт http://localhost:5173, API http://localhost:8000
```

Перед миграцией на рабочей базе сохраните копию `backend/data/app.db`.

## Автоматические проверки

```bash
yarn test:api
yarn typecheck
yarn build
uv run --directory backend ruff check app tests
```

Новые тесты должны покрыть сценарии ниже: словарь и метки фраз, занятия с фразами,
изоляцию колод, нормализацию апострофа и карточки выбора при 1–3 фразах в словаре.

## Ручные сценарии

1. **Слова не изменились (SC-003)** — до миграции запишите числа с главной и со
   «Статистики». После `yarn db:upgrade` они те же; «Учить слова» и «Повторить
   слова» работают как раньше.
2. **Словарь фраз (US1)** — «Фразы» → «Добавить»: `break the ice` — «растопить
   лёд», метка «идиомы». Фраза в списке со статусом «Новое», в «Словаре» слов её
   нет. Повторное добавление `Break  the ice` с тем же переводом — сообщение о
   дубле, введённое на месте. Кнопка с динамиком произносит фразу.
3. **Метки фраз отдельно (FR-022)** — «Настройки → Метки фраз»: «идиомы» со
   счётчиком 1. Создайте метку фраз с названием существующей метки слов — это
   разрешено, на вкладке «Метки» слов ничего не изменилось.
4. **Учить фразы (US2)** — заведите 6 фраз, «Учить фразы»: на знакомстве 5 фраз,
   «Уже знаю» добирает шестую. Пять раундов, в вариантах только фразы. В конце
   фразы «На повторении», срок через 1 день; лимит новых слов на сегодня не
   уменьшился.
5. **Повторить фразы (US3)** — переведите фразы в «На повторении» и сдвиньте срок
   (или подождите день). «Повторить фразы» берёт только фразы; ошибка в одном
   раунде → фраза в «Изучается», `lapses` + 1. «Повторить слова» не тронуто.
6. **Сравнение ответа (US4, SC-005)** — фраза `It's up to you.`: в письме ответ
   `its up to you` засчитан, `it is up to you` и `up to you it's` — нет.
7. **Мало фраз (R5)** — в словаре одна фраза: занятие проходит, карточки выбора
   решаемы.
8. **Статистика (US5)** — после занятий с фразами и со словами за день блоки фраз и
   слов показывают свои числа, не суммируя друг друга.
