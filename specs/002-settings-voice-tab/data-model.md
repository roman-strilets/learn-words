# Phase 1 — Data Model: настройка озвучки

Данных на сервере фича не заводит: таблиц, миграций и полей в схеме БД не появляется.
Всё описанное ниже живёт в браузере — в состоянии `SpeechProvider` и в `localStorage`.

## Сущности

### `VoiceOption` — один голос в списке

Обёртка над `SpeechSynthesisVoice`, которую отдаёт контекст.

| Поле | Тип | Смысл |
|---|---|---|
| `uri` | `string` | `voiceURI` браузера. Идентификатор выбора: именно он сохраняется |
| `name` | `string` | Имя голоса, очищенное от скобочного хвоста (`Karen (Enhanced)` → `Karen`) |
| `lang` | `string` | Языковой тег варианта (`en-US`, `en-GB`) — ключ группировки |
| `isDefault` | `boolean` | Голос, который браузер считает основным. Показывается пометкой |
| `voice` | `SpeechSynthesisVoice` | Исходный объект браузера, нужен для `utterance.voice` |

**Уходят из текущей версии**: `emoji` (аватарка по индексу) и `flag` — флаг переезжает
на уровень группы, аватарки исчезают вместе с `VoicePicker` (см. research.md, п. 2).

**Правила**:
- В список попадают только голоса, у которых `lang` начинается с `en` (регистр не важен):
  озвучиваются английские слова.
- Ограничения на количество нет — берутся все подходящие голоса (FR-002).
- `uri` уникален внутри списка; при совпадении остаётся первый — браузеры изредка отдают
  дубликаты одного голоса.

### `VoiceGroup` — языковой вариант

| Поле | Тип | Смысл |
|---|---|---|
| `lang` | `string` | Тег варианта, общий для голосов группы |
| `label` | `string` | Русское название: «Американский», «Британский», «Австралийский», … |
| `flag` | `string` | Флаг варианта; для неизвестного тега — 🌐 |
| `voices` | `VoiceOption[]` | Голоса варианта, отсортированные по `name` |

**Правила**:
- Известные теги берутся из карты (`en-US`, `en-GB`, `en-AU`, `en-CA`, `en-IE`, `en-IN`,
  `en-NZ`, `en-ZA`); неизвестный тег даёт группу с `label = lang` и 🌐 — голос остаётся
  доступным (FR-002, research.md п. 6).
- Порядок групп фиксирован картой известных вариантов, неизвестные идут после них по
  алфавиту тега. Порядок устойчив между открытиями страницы.
- Пустых групп не бывает: группа создаётся, только когда в ней есть голос.

### `SpeechSettings` — сохранённый выбор

Живёт в `localStorage`, ключ **`speech.voice`** (уже используется, формат не меняется).

| Значение | Смысл |
|---|---|
| `null` / ключа нет | Голос не выбран. Озвучивает голос, который браузер подбирает по `lang`. В списке активен «Системный голос» |
| `"<voiceURI>"` | Выбранный голос. Если такого голоса в системе нет — поведение как у `null` (FR-008) |

**Правила**:
- Значение не отправляется на сервер и не участвует в прогрессе (FR-011).
- Недоступное хранилище (приватный режим) не ломает страницу: выбор действует до конца
  сеанса — это уже обеспечивает `useLocalStorage`.
- Соседние ключи `speech.rate` и `speech.autoplay` этой фичей не затрагиваются: они
  сохраняются как раньше и остаются без интерфейса (Clarifications, вопрос 1).

## Состояния выбора

Список показывает ровно один активный пункт. Состояние выводится, а не хранится:

```text
сохранённый uri = null            → активен «Системный голос»
сохранённый uri найден в voices   → активен этот голос
сохранённый uri не найден         → активен «Системный голос»   (голос исчез, FR-008)
голосов нет вообще                → активен «Системный голос», рядом объяснение (FR-009)
синтеза речи нет                  → списка нет, только объяснение (FR-009)
```

Переходы:

| Из | Действие | В | Побочный эффект |
|---|---|---|---|
| любое | щелчок по голосу | этот голос активен | `speech.voice = uri`, звучит образец этим голосом |
| голос выбран | щелчок по «Системному голосу» | активен «Системный голос» | `speech.voice = null`, звучит образец без явного голоса |
| выбран | повторный щелчок по нему же | не меняется | образец звучит снова (US2, сценарий 2) |
| любое | браузер догрузил голоса | не меняется | список пополняется, активный пункт пересчитывается (FR-010) |

## Производные значения

- **`selected`** — `VoiceOption | null`: голос, найденный по сохранённому `uri`.
  `null` означает «системный голос» и показывается активным пунктом «Системный голос».
  **Отличие от текущего кода**: сейчас `selected = chosen ?? voices[0]`, то есть при
  отсутствии выбора активным показывается первый голос списка — интерфейс утверждал бы,
  что голос выбран, когда он не выбран, и пункт «Системный голос» никогда не был бы
  активным. Подмену нужно убрать; за «чем озвучивать по факту» отвечает `chosen`,
  который уже честно равен `null` (FR-007).
- **`groups`** — `VoiceGroup[]`: чистая функция от списка голосов, пересчитывается при
  каждом обновлении `voices`.
- **`error`** — `string | null`: человекочитаемая причина последнего отказа озвучки
  (`not-allowed` → запрет браузера, прочее → отказ голоса). Сбрасывается при новой
  успешной попытке. Коды `canceled` и `interrupted` ошибкой не считаются — это
  собственный `cancel()` провайдера.

## Образец для прослушивания

Фиксированная английская фраза, одна на все голоса, не зависящая от занятия и словаря
(раздел Assumptions спецификации). Хранится именованной константой в модуле страницы —
«магических» строк по коду не разбрасывается.
