# Quickstart: проверка упражнения «Напишите слово по-английски»

## Автоматические проверки

```bash
yarn test:api
yarn typecheck
yarn build
uv run --directory backend ruff check app tests
```

Тесты должны покрыть:
- `test_exercises.py`: карточка `writing_ru_en` содержит только `type`, `word_id`,
  `prompt == translation`; табличная проверка ответов (`knife` ✓, ` KNIFE ` ✓,
  `to budge` для `budge` ✓, `knif` ✗, `""` ✗, `None` ✗, синоним ✗).
- `test_api.py`: план занятия — пять раундов, `writing_ru_en` стоит четвёртым;
  `used_hint: true` на `writing_ru_en` пишется в журнал как `false` с качеством 5;
  слово без ответа в новом раунде не сдвигает расписание на `finish`.
- Существующие тесты, опирающиеся на `EXERCISE_ROUNDS`, проходят без правок
  чисел: число карточек берётся из длины кортежа. Имена и комментарии
  «четыре раунда» исправлены.

## Ручная проверка (`yarn dev`)

1. «Повторить слова» (или «Учить слова» после знакомства). Пройти три раунда.
2. Четвёртый раунд называется «Написание: рус → англ». На карточке — русский перевод
   и пустое поле с фокусом. Лампочки, ячеек и звука нет, клавиша подсказки ничего
   не делает.
3. Ввести правильное слово и нажать Enter: ответ засчитан, после него слово
   произносится (если включена автоозвучка).
4. Ввести слово с опечаткой: ответ не засчитан, показано правильное слово, карточка
   вернулась в конец раунда.
5. После раунда идёт «Аудирование», последним.
6. В DevTools → Network ответ плана не содержит английского слова в карточках
   `writing_ru_en`.
