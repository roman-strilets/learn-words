# Quickstart: проверка импорта слов из CSV

Формат запроса и ответа — в [contracts/api.md](contracts/api.md), правила строк —
в [data-model.md](data-model.md).

## Подготовка

```bash
cp backend/data/app.db backend/data/app.db.bak-before-import   # прогресс не восстанавливается
yarn dev
```

Файлы для проверки складываются в scratchpad, а не в репозиторий.

## 1. Автоматические проверки

```bash
yarn test:api
uv run --directory backend ruff check app tests
yarn typecheck
yarn build
```

Ожидается: все зелёные. Новые тесты:

- `backend/tests/test_word_import.py` — табличные тесты `parse_import`: оба
  разделителя, BOM, русские и английские заголовки, кавычки с «;» и переводом
  строки внутри, длины, пустые строки, ошибки уровня файла, номера строк.
- `backend/tests/test_api.py` — `POST /api/words/import`: создание со статусом
  «Новое» и метками, слияние перевода, пример только в пустое поле, выбор записи
  при нескольких значениях, неизменность `progress` и журналов, идемпотентность,
  откат при ошибке, 413/422.
- `backend/tests/test_import.py` — консольный импорт после переноса общих функций
  ведёт себя как раньше.

## 2. Новые слова с метками (US1)

Файл `words-ru.csv` (UTF-8, разделитель «;»):

```csv
слово;перевод;пример;перевод примера;метка
saucepan;кастрюля;Put the saucepan on the stove.;Поставь кастрюлю на плиту.;Кухня
whisk;венчик;;;"кухня; Посуда"
ladle;половник;;;
```

«Словарь» → «Импорт из CSV» → выбрать файл → «Импортировать».

Ожидается:

- отчёт: прочитано 3, добавлено 3, создано меток «Кухня», «Посуда»;
- в списке три слова со статусом «Новое», у `whisk` метки «Кухня» и «Посуда», без
  перезагрузки страницы;
- в «Настройки → Метки» одна метка «Кухня» с двумя словами.

## 3. Повторный импорт (US2)

1. Импортировать `words-ru.csv` ещё раз. Ожидается: добавлено 0, дополнено 0, без
   изменений 3.
2. Выучить `saucepan` через «Учить слова» и запомнить её срок повторения.
3. Добавить в файл строку `saucepan;сотейник;;;Посуда` и импортировать.
   Ожидается: перевод `saucepan` — «кастрюля; сотейник», метки «Кухня» и «Посуда»,
   статус и срок не изменились, отчёт: дополнено 1.

## 4. Файл из англоязычного редактора и `dictionary.csv`

Импортировать поставляемый `dictionary.csv` (английские заголовки, разделитель «,»,
BOM). После `yarn setup` ожидается: прочитано ≈ 7 700 строк, добавлено 0,
дополнено 0, за время меньше 10 секунд (SC-002, SC-003).

## 5. Ошибки (US3)

| Файл | Ожидается |
|---|---|
| строки без перевода и со словом длиннее 128 символов | остальные импортированы; отчёт называет номера строк и причины |
| заголовок `слово;пример` | 422 «Нет обязательных колонок: перевод…»; словарь не изменился |
| тот же `words-ru.csv`, сохранённый в Windows-1251 | 422 про UTF-8 |
| пустой файл | 422 «Файл пустой» |
| файл больше 5 МБ | панель сообщает о пределе, запрос не уходит; через curl — 413 |
| лишняя колонка `источник` | импорт прошёл, отчёт называет её игнорированной |

Проверка через curl:

```bash
curl -s -X POST localhost:$UVICORN_PORT/api/words/import \
  -H 'Content-Type: text/csv' --data-binary @words-ru.csv | jq
```
